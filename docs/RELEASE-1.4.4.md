# 拾音 PickAudio v1.4.4

版本：1.4.4 / code 17。Android 16，数据库仍为 v5。

- QQ 直连遇到临时后端错误时，对同一原曲编号、同一音质重试一次，仍受音源总超时约束，不替换其他录音。
- 在线音频连续 20 秒没有进展，或单次缓冲持续 60 秒时，按原进度重新连接，最多两次；显式暂停和切歌会取消恢复，临时音频焦点中断不计为卡顿。
- 歌单自动跳过失败歌曲时保留播放意图及前台服务状态，避免等待下一首时先撤掉后台播放。连续三首失败停止，顺序播放到末尾失败不绕回第一首；音质不匹配也使用相同失败处理。
- 播放器创建和重置异常进入可重试错误状态，旧音频流的迟到错误不会覆盖正在准备的新歌曲。
- 诊断导出增加设备型号及系统保留的最近五次进程退出类别、时间和内存统计，便于区分崩溃、ANR、内存不足和系统终止；不导出歌曲、URL、脚本或堆栈内容。

验证范围、已复现问题与设备限制见 [验证记录](VALIDATION-1.4.4.md)。沿用原签名，可覆盖旧正式版。
