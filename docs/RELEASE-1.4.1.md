# 拾音 PickAudio v1.4.1

发布日期：2026-10-08。内部版本号：14。安装要求：Android 16（API 36）及以上。

## 播放稳定性

- 修复歌曲播放中缓冲、短暂音频焦点中断被误判为暂停的问题。后台服务在这些场景中继续保持前台状态，缓冲或中断结束后继续播放。
- 调整后台恢复播放顺序：先确认播放服务进入前台，再申请音频焦点，适配 Android 16 的后台音频限制。
- 修复暂停后迟到的媒体服务启动请求未满足前台时限的风险；保留暂停通知的媒体控件，并处理服务启动被系统拒绝的情况。
- 在线连接失败、超时或指定的地址过期错误，会重新解析同一首歌、同一音质并保留进度，最多自动恢复两次。主动暂停或切歌会取消恢复。
- 音源解析超时显示可重试错误；播放器和迷你播放器的播放/暂停按钮与当前播放意图一致。

## 内置音源和外观

包含 v1.4.0 的内置星澜聚合音源 StellarWave v3.2.0，首次安装默认用于网易云和 QQ；升级保留已有自定义绑定及明确停用的平台。音乐源管理仍可选回原备用线路。歌曲可用性及实际音质以外部音源和文件检测结果为准。

设置 → 外观提供雾蓝、松绿、鸢紫、玫瑰、琥珀、青碧六种配色，适配深浅模式，即时生效并保存到偏好及备份。
