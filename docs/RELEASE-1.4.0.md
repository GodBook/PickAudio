# 拾音 PickAudio v1.4.0

发布日期：2026-10-07。内部版本号：13。安装要求：Android 16（API 36）及以上。

## 内置星澜音源

安装包内置星澜聚合音源（StellarWave）v3.2.0，首次安装默认用于网易云和 QQ 音乐，无需另行导入 JS。原脚本、版本和作者注释完整保留，文件 SHA-256 为 `a1c565851dea2e4209a2695a4e5af27f6425121aea3510510d3cc70c317b7c34`。

升级时，仅将原先使用拾音默认聚合线路的平台切换到星澜；已有自定义源绑定和明确停用的平台状态保留。首次切换之后，用户可在音乐源管理中选回原线路，重启不会再次覆盖选择。两种内置源都可用于平台绑定，内置源不可删除，自定义脚本仍可导入或删除。

补齐 LX 脚本的 AES-ECB/CBC 加密、表单 POST、请求超时和原脚本信息支持。星澜初始化声明的网易云、QQ 音质为标准 128K、高品质 320K 和 FLAC；实际文件音质继续按原有播放与下载检测结果展示。歌曲可用性仍取决于外部平台和脚本后端。

## 六种主题配色

设置 → 外观增加雾蓝、松绿、鸢紫、玫瑰、琥珀和青碧六种配色。每种配色均可搭配跟随系统、浅色或深色，按钮、导航、播放进度、歌词高亮和背景同步更新。

选择即时生效并持久保存；偏好备份包含配色，恢复旧备份时保留本机已有配色。旧版本升级默认保留雾蓝外观。
