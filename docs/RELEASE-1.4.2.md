# 拾音 PickAudio v1.4.2

发布日期：2026-10-08。内部版本号：15。安装要求：Android 16（API 36）及以上。

## QQ 播放与失败恢复

- 修正内置星澜音源 QQ 官方线路的播放参数：歌曲 MID 用于标识原录音，媒体 MID 用于生成音频文件名，避免搜索后请求了错误的文件。
- 音源后端全部失败时显示简短、可重试的提示，保留完整异常供诊断。错误提示最多显示三行，错误和重试操作放在固定控制区，小屏和大字体下也能直接操作。
- 播放服务退出后保留当前的播放错误或版本选择状态，重试会重新建立播放连接；失败后仍可切换并播放其他歌曲。
- 内置脚本升级按摘要更新，保留自定义音源绑定、明确停用状态和原有用户数据。

内置音源保留 StellarWave v3.2.0 的原作者及许可注释，本版对 QQ 文件编号使用作了局部修正。歌曲可用性仍取决于平台授权、网络和音源后端；平台拒绝播放时会显示失败提示，不保证每首 QQ 歌曲均可播放。
