# 拾音 PickAudio v1.3.0

发布日期：2026-10-07。内部版本号：10。安装要求：Android 16（API 36）及以上。

本次更新集中改善播放、下载和数据恢复的可靠性，并显著缩小安装包。

## 更新内容

- 播放队列中的重复歌曲分别保留位置和进度，系统媒体控制与应用队列使用同一套播放逻辑。修复前台服务超时和通知反复更新导致后台播放停止的问题，支持后台自然切歌、通知暂停和直接返回播放器。
- 更新下载可以真正取消；重新开始时，旧任务不再覆盖新状态。安装前检查文件完整性、应用身份、签名和版本。
- 下载暂停、继续、取消和重试更稳定；遇到进程中断或文件发布未完成时自动核对状态。已完成文件失效时显示需要处理，并允许重新下载。批量结果显示成功和失败数量，只重试失败项。
- 导入、删除、歌单和收藏的关联保持一致。删除中断后只核对结果，不自动继续删除。失效本地文件进入待修复列表，支持重新关联和人工确认候选文件。
- 大曲库使用后台搜索索引和按歌单范围查询，减少重复加载与界面订阅。歌词按歌曲刷新，支持 GB18030、UTF-8 BOM、多时间标签和偏移；离线时继续使用已有缓存。
- 搜索保留各平台的结果和错误状态，完善分页结束判断及“全部”来源摘要。改进批量反馈、原位撤销、收藏时间和排序冲突提示。
- 备份导出与导入采用一致的容量规则，新格式继续读取旧 v1/v2 备份；恢复中断后可继续，避免歌曲和偏好出现部分恢复。音频文件和完整音源脚本仍需另行保存。
- 缓存按歌曲、来源、音质和资源身份区分，支持 64/256/1024 MiB 容量及低空间调整。本地音频不经过网络缓存，设置中可主动导出不含歌名、文件地址和凭据的本地诊断。
- 完善脚本网络边界、取消和异常处理，修复 Unicode、emoji、MD5 与 JNI 资源释放。自定义音源的网络请求使用 HTTPS，本机及内网地址受访问限制。
- 开启正式包代码和资源裁剪，保留 arm64-v8a、x86_64 与 16 KiB 对齐。设置中可离线查看第三方许可。

## 升级说明

- 使用原项目签名覆盖旧正式版，迁移歌曲、歌单、收藏、队列、歌词和下载记录。升级前可在设置中导出手动备份。
- 安装要求继续保持 Android 16（API 36），本次未扩大系统版本支持范围。
- 系统自动备份和设备迁移不搬运应用私有状态；换手机使用手动备份，并另行保存音频文件和完整音源脚本。
- 在线歌曲、音质及音源可用性取决于对应平台、网络和音源。

[GitHub CI](https://github.com/GodBook/PickAudio/actions/runs/37504251297) 已完整通过：单测、Debug/Release 构建、Lint、Room schema，以及 Debug/裁剪验证变体各 51 项 API 36 设备测试，均无测试失败或跳过。依赖锁定和严格摘要校验保持开启。

在专用 API 36 模拟器上，使用原签名直接覆盖 v1.2.0 正式版，Room v2→v4 迁移成功，歌曲、资源、在线引用、歌单、收藏时间、重复队列、手动歌词与 300ms 校准、自定义音源和设置保留；1024 字节暂停下载数据保留，数据库完整性正常。完整证据及发布检查点见 [优化执行记录](https://github.com/GodBook/PickAudio/blob/main/docs/OPTIMIZATION-EXECUTION.md)。模拟器结果不等同于实体设备帧率、耗电、蓝牙或 TalkBack 验收。
