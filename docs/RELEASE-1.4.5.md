# v1.4.5 随机播放卡死修复

版本：1.4.5 / versionCode 18。数据库仍为 v5，沿用原项目签名，可覆盖旧正式版。

修复随机播放过程中歌曲突然停止、界面无响应的问题。原媒体会话时间线只为当前歌曲单独指定随机的上一首/下一首，其他歌曲仍按列表顺序连接；部分组合会形成无法结束的环路。Media3 在主线程比较或遍历该时间线时可能无限循环，系统随后可能因 ANR 终止应用。

本版使用覆盖全部队列条目的完整随机顺序，同一时间线的首尾、正向与反向索引保持一致；关闭循环时遍历会正常结束，开启列表循环或单曲循环时才按相应规则重复。自然切歌、重复歌曲条目及队列编辑保留独立条目身份。

媒体会话时间线同时固定歌曲时长和随机顺序快照，避免旧时间线随当前播放器变化；手动选择随机池中的歌曲后，会从待播池移除当前条目，避免紧接着再次选中同一条目。播放模式变化会通知媒体控制器更新列表。

验证范围、回归结果及正式包信息见 [v1.4.5 验证记录](VALIDATION-1.4.5.md)。
