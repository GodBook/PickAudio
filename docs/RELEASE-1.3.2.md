# 拾音 PickAudio v1.3.2

发布日期：2026-10-07。内部版本号：12。安装要求：Android 16（API 36）及以上。

试听歌曲不再自动进入曲库。搜索结果的 ＋、播放器、歌曲菜单和下载完成页提供“加入曲库”；喜欢、歌单、队列和下载记录独立保存。主动扫描或导入的手机音频仍加入曲库。普通“移出曲库”保留歌单、喜欢和播放队列。

数据库从 v4 迁移到 v5，保留原有记录与关联。旧版自动记录的纯在线试听歌曲从曲库视图隐藏，本地音频保留。新版备份保存曲库归属，恢复时不会把试听记录重新加入曲库。

修正 QQ/LX 音源的数值歌曲 ID、歌曲 MID、媒体 MID、专辑及音质字段。旧记录缺少元数据时按原曲 MID 补取，内置 QQ 路线先请求原曲地址，拒绝将试听片段或其他歌曲的地址作为原曲。

QQ 官方接口在本次实测中拒绝匿名播放请求，返回 `104009`。平台未提供原曲地址时仍需配置可用的 QQ 音源，或手动确认其他平台候选版本；本次更新不宣称解决平台播放授权限制。

整理曲库、在线搜索、歌曲行和迷你播放器的布局，统一搜索框、文字层级和留白。播放器的进度与播放控件固定在底部，歌曲信息和长错误提示在上方滚动；小屏、大字号下仍可直接暂停和切歌。
