# v1.5.0 操作体验与性能优化

版本：1.5.0 / versionCode 19。数据库保持 v5，最低系统扩展为 Android 15（API 35），target/compile 仍为 API 36。

搜索多选现在遵循界面范围：综合页选择已显示结果，单个平台选择已加载结果，切换平台清空选中状态。查看音乐源后不再无条件重新播放；更换源时保留当前歌曲、进度和播放意图，音质不受支持时提示选择。

批量加入播放队列改为一次更新，拖动排序结束后统一提交，待写快照只保留最新状态。媒体会话复用不可变时间线和媒体信息，保留重复歌曲身份、随机顺序及有限遍历规则。

已完成下载的文件核验移到后台；下载历史分页加载，批量命令显示实际处理报告。进度显示和数据库检查点分开更新，通知内容不变时不重复刷新。暂停、失败、完成与发布阶段仍即时保存。

减少音源初始化、音质能力查询、未变化音频信息写入及偏好发射。重复导入有可信修改标识的音频时复用已有信息，封面维护按批次执行；短音频过滤计入完整扫描统计。

播放器局部刷新进度，歌词按需加载，字号拖动即时预览后保存。补充曲库、歌单、下载的加载反馈和查询恢复。脚本 Promise 等待改为事件通知，播放与缓存验证复用连接池；本地播放使用本地 wake 模式并关闭网络停滞轮询。

87 项 JVM 测试、USB 小米 9 SE（Android 15）Debug/validation 各 102 项，以及 CI 的 API 35/36 × Debug/validation 四组各 102 项回归通过。原签名 1.4.5→1.5.0 覆盖升级保留设置、歌单、收藏、歌词校准、重复队列、进度及暂停下载；原签名正式包与手机相同生产 DEX 的后台播放、自然切歌、通知和界面恢复检查通过。手机已安装并验证原签名正式包的文件导入、本地播放和真实在线搜索/音频解码。

同机 Debug 测量中，1,000→2,000 条队列操作的同步主线程 API p95 从 583.96 ms 降到 20.55 ms（约 96.5%，不含异步落库）。本版实际生产 DEX 的万首曲库场景，10 次进程冷启动显示时间 p95 为 499 ms，20 次滑动的 683 帧 p95 为 13 ms；这些单版本数据不能与 Debug 基线直接计算整体提升比例。测量方法、CI 首轮超时及复跑、外部音源限制见 [完整验证记录](VALIDATION-1.5.0.md)。

正式 APK 大小 8,291,613 字节（约 7.91 MiB），沿用原项目签名，支持覆盖旧正式版。SHA-256：`fe40c85bfeeda6403f162d1be31f25b4935738846a40c4b120d1a55c7b01f281`。

下一首预解析/连续媒体准备、无缝播放、缓冲调参、Macrobenchmark/Baseline Profile 和脱离 USB 的配对耗电实验保留为后续专项。Debug 基线未证实启动或滚动稳定改善，USB 充电测试不用于宣称续航增益；长时间内存、并行下载帧、实体蓝牙与 TalkBack 按后续范围验收。
