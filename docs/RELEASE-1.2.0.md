# 拾音 PickAudio 1.2.0 更新说明

文档日期：2026-10-06 · 更新主题：日常使用体验优化

1.2.0 围绕找歌、播放、整理曲库和离线下载优化日常体验。导入进度更直观，歌曲管理更方便，搜索与播放失败时有明确的处理入口，歌词、下载和备份也提供了更完整的反馈。

## 界面更清楚，操作更顺手

- 统一曲库、搜索、歌单和队列中的歌曲列表样式，清楚标注本地、已下载、在线平台和当前播放状态。
- 调整浅色与深色主题的配色、系统栏显示和按钮布局，改善小屏幕及大字号下的歌曲信息与歌词显示。
- 完善空列表、无搜索结果和失败提示，提供导入、清除筛选、重试或配置音乐源等操作入口。

## 导入和整理曲库更方便

- 将扫描手机歌曲、多选音频文件、递归导入文件夹统一放到“导入音乐”入口。
- 导入时显示进度，以及新增、跳过和失败数量；支持中途取消，已导入歌曲保留。
- 支持按歌手、专辑、文件夹和最近播放浏览，按歌曲名称、歌手名称、时长或最近添加排序，并筛选本地、已下载和在线歌曲。
- 扫描手机歌曲时遵循“过滤 30 秒以下短音频”设置；手动选择文件或文件夹导入时保留短音频。

## 歌单和队列管理更省事

- 完善歌曲多选操作，可批量加入歌单、下载或管理播放队列，歌单内可批量移除成员。
- 在“加入歌单”窗口中直接“新建并加入”，减少切换页面的步骤。
- 支持拖动调整自建歌单、歌单成员和播放队列的顺序；清空播放队列后可以撤销。
- 修复歌曲信息更新或歌单改名时可能丢失歌单成员、收藏等关联的问题。

## 搜索和播放反馈更明确

- 网易云与 QQ 音乐分别加载结果、分页和重试；某个平台失败时，仍可查看另一平台的结果。
- 修复连续更换搜索关键词时旧结果覆盖新查询的问题；快速切歌时保留最后一次选择。
- 修复检查更新时将当前版本或旧版误报为新版的问题。
- 播放器显示解析、缓冲和失败状态，失败后可重试、选择其他音质或更换音乐源；本地文件失效时可重新关联音频。
- QQ 原版本不可用时，展示其他平台的候选歌曲，确认后再切换歌曲信息与歌词，方便核对原版、现场版等不同录音。
- 音源管理展示支持的平台、音质和兼容性测试结果，导入脚本后可直接选择使用的平台。

## 歌词更好读，也更好调整

- 缓存在线歌词与翻译，完善加载、无歌词和失败提示，支持重新获取歌词。
- 支持手动导入 LRC 歌词，文件夹导入时自动匹配同名 LRC；歌词校准按歌曲分别保存。
- 可调整歌词字号和翻译显示；手动浏览后自动恢复跟随，也可直接回到当前歌词。
- 改善小视口和大字号下歌词初始空白、显示空间不足的问题。

## 下载进度和音质更透明

- 下载管理按“进行中”“已完成”“需处理”分组，显示中文状态、进度、速度、预计剩余时间和失败原因。
- 支持批量暂停、继续、重试和取消；下载完成后可直接播放或查看文件。
- 默认仅在 Wi-Fi 下下载，可在设置中允许移动网络，新任务会遵循该设置。下载中断后保留进度，服务器支持且文件一致时续传，否则重新完整下载。
- 默认播放音质与下载音质可修改并实际应用，下载时只显示当前音源支持的音质选项。
- 下载后检测实际音频格式、FLAC 位深和可解码性，显示校验后的音质；请求的无损规格不符时给出失败提示，可选择其他音质重试。
- 完成的歌曲保存在手机公共目录 `Music/PickAudio`，未完成的下载单独保存，清理缓存时保留暂停任务的进度。

## 备份和缓存管理更清楚

- 备份包含歌单、收藏、歌曲记录、歌词与校准、偏好设置和音源描述，并增加完整性校验。
- 恢复前可预览内容并选择是否恢复偏好设置；恢复后显示新增、合并和待关联音频的统计，相同歌单增量合并，重复恢复不会复制歌单。
- 音频缓存、封面缓存和无任务的临时下载文件可分别清理，保留正式下载、歌单、收藏、手动歌词和暂停下载进度。

## 常用功能入口

| 想做什么 | 操作入口 |
|---|---|
| 导入本地歌曲 | 曲库 → 导入音乐 |
| 批量整理歌曲 | 曲库、搜索或歌单详情 → 多选，也可长按歌曲进入多选 |
| 调整音质与下载网络 | 设置 → 音乐与下载 |
| 导入歌词或调整显示 | 播放器 → 更多 → 导入本地歌词／歌词字号与翻译 |
| 查看下载进度 | 曲库右上角下载图标 → 下载管理 |
| 配置或测试音源 | 设置 → 音乐源管理 |
| 清理缓存或导出备份 | 设置 → 存储与缓存／备份与恢复 |

## 升级须知

- 安装要求为 Android 16（API 36）及以上。
- 使用原签名安装包覆盖升级时，迁移并保留已有歌曲、歌单、收藏、歌词和下载记录。升级前可在“设置 → 备份与恢复”导出备份，旧版备份仍可导入。
- 备份保存歌曲记录，不包含音频文件和完整音源脚本；换手机时需另行保存这些文件，恢复后可按提示重新关联音频、导入脚本。
- 可用歌曲与音质取决于网络、音乐平台和当前音源。内置网易云线路提供标准／高品质请求；使用无损音质需音源支持并通过实际文件校验。
