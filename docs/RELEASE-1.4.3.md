# 拾音 PickAudio v1.4.3

发布日期：2026-10-08。内部版本号：16。安装要求：Android 16（API 36）及以上。

1. 新增内置「拾音 QQ 直连」，按 QQ 原曲编号解析音频，提供标准、高品质和 FLAC 档位。返回前核对歌曲编号并检查音频内容；试听片段、其他歌曲和失效地址不会进入播放器。原默认 QQ 线路在升级后自动切换一次，自定义音源、明确停用和后续手动选择保留。
2. 设置首页改为外观、播放与下载、歌词、存储与缓存、备份与恢复、关于拾音六个分类。每项显示当前设置摘要；详细选项放在独立页面，歌词字号可即时预览，版本、许可和诊断集中到关于页面。
3. 从搜索结果试听后，系统返回键先收起播放器，仍停留在原搜索页；保留查询、平台、结果和滚动位置。播放器顶部收起按钮使用相同行为。

安装包沿用原项目签名，可覆盖旧正式版。内置 QQ 音源通过公开服务解析，音乐可用性仍受服务和平台授权影响；实际编码、码率和文件格式以音频检测为准。

74 项 JVM 测试及 Debug／裁剪验证版各 82 项 API 36 设备测试通过，构建、Lint 和 schema 检查通过。原签名 1.4.2 → 1.4.3 覆盖升级保留设置、歌单、收藏、队列、进度、自定义音源与暂停下载。
