# v1.3.2 修复与发布记录

源码与正式版本：1.3.2 / code 12。已于 2026-10-07 发布 [GitHub Release](https://github.com/GodBook/PickAudio/releases/tag/v1.3.2)，源码提交为 `3e1e45f21f1b94402706f113f30250fd63895822`。

曲库现在使用独立的加入标记。试听、播放队列、我喜欢、歌单和下载记录仍可保存和恢复，但不会自动出现在曲库。搜索结果旁的 ＋、歌曲菜单、播放器及下载完成页提供“加入曲库”。手机音频通过用户主动扫描或导入加入曲库。普通“移出曲库”保留歌单、喜欢和队列。

Room 数据库从 v4 升至 v5。迁移保留本地音频记录的曲库归属，隐藏旧版自动写入的纯在线试听记录，保留它们的歌单、喜欢和队列关联。备份继续使用兼容的 v3 格式，额外保存曲库标记；恢复新版备份不会把试听记录重新加入曲库。

QQ 内置路线增加原曲播放地址请求，区分歌曲 MID 与媒体 MID，按所选音质请求文件，并核对返回地址所属的歌曲。不会把试听片段、测试文件或其他歌曲的地址当作原曲。自定义 LX 音源保留数值歌曲 ID，补全 `songId`、`strMediaMid`、`name`、`singer`、专辑及音质字段；旧记录缺少字段时按原曲 MID 补取元数据。QQ 流媒体请求带对应的 Referer。

QQ 官方接口在本次网络实测中对匿名请求返回 `104009`，未提供原曲地址。修正应用解析不等于取得平台播放授权；平台拒绝原曲时仍需配置可用的 QQ 音源，或手动确认其他平台候选版本。没有静默替换录音。

界面沿用原生 Compose，统一搜索框、字级和页面留白。曲库收起空库无用的筛选项，分开导入、筛选和歌曲列表；在线搜索按平台分区，批量操作使用单行工具栏；歌曲操作移到信息区旁，增加明确的曲库按钮。播放器统一封面/歌词标签，合并重复错误提示；歌曲信息区域可以滚动，进度和播放控制固定在底部，小屏或错误提示较长时仍可直接操作。
